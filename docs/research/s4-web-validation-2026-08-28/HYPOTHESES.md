# S4 event-evaluation hypothesis registry

Questa lista è congelata prima della sintesi del corpus. Una fonte può supportare, contraddire,
qualificare o non trattare ciascuna ipotesi.

| ID | Ipotesi da verificare o confutare |
|---|---|
| H01 | Il future return non è ground truth semantica né prova causale della news. |
| H02 | Il sentiment/event content delle news contiene informazione incrementale sui return futuri. |
| H03 | Positive e negative news hanno velocità di incorporazione e persistenza asimmetriche. |
| H04 | T+63 è difendibile come test pre-registrato del mandato S4, soprattutto come persistence test. |
| H05 | L'information event, non l'articolo grezzo, è l'unità di inferenza appropriata. |
| H06 | Novelty, relevance, directness, source quality ed event type migliorano il rapporto segnale/rumore. |
| H07 | Abnormal return market/sector-adjusted è più adatto del raw return per score alignment. |
| H08 | Issuer-specific, sector/theme e macro richiedono outcome e unità statistiche differenti. |
| H09 | Neutral-news e matched no-news sono controlli distinti e complementari. |
| H10 | Il primo timestamp realmente osservabile/eseguibile deve determinare accountability e anchor. |
| H11 | As-produced score e frozen rescore devono restare lane parallele e versionate. |
| H12 | Backfill storico è discovery; una replica forward untouched è necessaria per promotion. |
| H13 | Conservare tutte le feature aumenta discovery ma richiede trial ledger e controllo molteplicità. |
| H14 | Gross, accessible, net e captured opportunity devono essere separate con policy controfattuale congelata. |
| H15 | Accuracy semantica richiede annotazione umana rappresentativa, cieca e distinta dalla coorte diagnostica. |
| H16 | Una first pipeline loss cause esclusiva rende il capture gap diagnosticabile. |
| H17 | La gamba negativa è informativa/veto/shadow-short, non missed long su ticker non detenuto. |
| H18 | Un backfill senza historical available-at, PIT universe e delisting evidence non misura accountability live. |
| H19 | Un modello contestuale/LLM può aggiungere informazione rispetto a un baseline lessicale semplice. |
| H20 | L'effetto varia materialmente per event type; PEAD non è trasferibile a ogni news generica. |
| H21 | Coverage, text adequacy, provider e source class modificano la misurazione e la trasferibilità. |
| H22 | Attention, size, liquidity e information environment moderano underreaction e predictability. |
